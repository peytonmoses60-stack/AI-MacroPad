# Agent Pad

The working brief for any agent in this repository is `CLAUDE.md`. It applies to you whichever agent you are: read it first, then `README.md`.

- `docs/news-for-codex-2026-11-23.md` has the latest results from the Windows PC and the open work, in priority order.
- `docs/project-background.md` has the research and the decisions behind the project.

The rules in `CLAUDE.md` are not optional. The two that matter most: no shortcut may ever send Enter or Space, and approvals only ever go through the permission hook, never through keystrokes.
